# 03: 新建的节点不再显示「8123」

**What to build:** 刚建好的节点在列表里显示「未注册」；把安装命令在目标机器上执行、
agent 连上控制面之后，同一行变成「在线」。

今天这一列显示的是数据库默认值 `'8123'`——某次把端口写进了状态列——而后端没有任何
一处写过它，所以「在线」那条分支永远不会命中，每个节点从建出来那天起就一直挂着一个
端口号当状态。管理员看着这一列做判断，看到的是假的。

这次只做到「未注册 / 在线」。「在线」的含义是这个节点向控制面注册过，不是此刻可达
——真正的离线判定要么靠心跳、要么靠最后见到时间，仓库里目前一个这样的信号都没有，
那是另一件事。页面不该暗示它知道得更多。
