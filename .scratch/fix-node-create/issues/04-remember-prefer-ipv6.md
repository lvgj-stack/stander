# 04: 「默认走 IPv6」被节点记住

**What to build:** 创建节点时勾了「默认走 IPv6」，这个选择跟着节点一起存下来。之后
从节点列表里再打开这个节点的安装命令，拿到的命令和创建那一刻给出的完全一样，同样带
着 `--prefer-ipv6`。

今天这个开关只活在创建对话框的内存里：请求里带着它，但创建从不把它存进节点。于是从
列表打开安装命令时没人知道该不该加这个参数，同一个节点从两个入口能拿到两条不同的
命令，照着后一条装出来的 agent 注册的是 IPv4 地址。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 勾选后创建，再从列表打开安装命令，命令带 `--prefer-ipv6`
- [ ] 不勾选创建，再从列表打开安装命令，命令不带
- [ ] 创建当场弹出的命令与之后从列表打开的命令逐字一致
- [ ] 节点列表接口把这个偏好带回来；存量节点视为未勾选
- [ ] 测试钉住这个字段真的被提交并被存下来——只测换算或只测表单都看不见「字段被丢掉」
      这个失败（prior art：安装命令对话框那两条测试）
