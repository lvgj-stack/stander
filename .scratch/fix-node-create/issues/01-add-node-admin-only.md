# 01: 建节点收归管理员，创建路径收成一条

**What to build:** 只有管理员能建节点。普通用户手写的建节点请求在碰到数据库之前就被
拒绝，拿到的是权限类错误。管理员建节点走唯一一条路径：写一行节点，把 key 交回去，
页面照旧弹出安装命令。

原先专门给非管理员写的那条分支——建完节点顺手给自己写一行资源归属——随之消失。跟着
一起消失的是它带来的三样东西：第二次写库（那行归属）、插完之后按 key 的回查、以及
那次回查被丢掉的错误值。管理员绕过所有 per-resource 判定，本来就不需要归属行；创建
只剩一次写库，也就不再有「节点建了但归属没建成」这个中间态，不必再为它包事务。

谁能看见哪个节点，仍然只由「转发用户 › 资源授权」里按用户写的行决定。

**Blocked by:** None (can start immediately)
